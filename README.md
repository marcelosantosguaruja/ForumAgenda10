## Sistema de controle de estoque 📱
Realizar o teste de estoque para controle de mínimo necessário.

Orientação geral para o perfeito funcionamento do sistema.

1️⃣ Informe qual o produto será lançado na simulação do estoque.
2️⃣ Informe agora a quantidade adquirida
3️⃣ Informe a quantidade vendida.

O sistema fará a contagem de quanto foi comprado - a quantidade vendida e retornará a informação de quanto há em estoque 
consequentemente, retornará a informação se é suficiente ou precisa repor.
